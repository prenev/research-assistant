:::danger No participant-level data
This notebook must **never** hold UK Biobank participant-level data.
:::

## What belongs here

- Protein names and panel annotations
- Literature, plans, decisions and notes
- **Permitted aggregate results** only

## What does not

- Any row-level or participant-level data, in any form (tables, CSVs, screenshots, plots of individual points)
- Outputs that could identify participants or fall below the disclosure thresholds set by the data access terms

## How the site enforces this

- The results form shows a persistent policy warning.
- If the number of events is below the minimum set in site settings (default 10), you must tick a confirmation that the figure is permitted to be shown.
- Image uploads in the editor carry a reminder not to upload outputs containing participant-level data.
- There is no feature for uploading participant data. The only CSV import is the Zotero literature export.
